#461 — capturing a bare <img> as the root never inlined it

snapdom(imgEl) where imgEl IS the capture root, not a descendant. inlineImages used to build its worklist with clone.querySelectorAll('img'), which never matches the element it's called on — so the root's src stayed an external URL and svg-as-image rasterization (checkerboard = transparent) refused to load it. Before the fix this came out blank.
