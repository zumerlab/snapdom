A height coming from a stylesheet rule must survive the clone

Column 1: three transparent .band wrappers whose height: 120px comes from the stylesheet above — no style attribute anywhere. Column 2: the same three bands with style="height:120px" written inline; that path always worked. Before the fix the two captures disagreed — the stylesheet version came out at the right total height but with the three outlined boxes collapsed to one line of text each and stacked at the very top, the rest of the canvas blank, while the inline version came out correct. The guard meant to detect an author-fixed height compared the used height against el.scrollHeight, which returns the padding-box height whenever the content is shorter than the box: scrollHeight === 120 === used height, difference 0, so it read as auto and the height was deleted.
