#462 — <picture> <source> elements override the inlined <img> src

A <picture>'s <source> out-ranks the <img>'s own src, so it survives into the exported SVG still pointing at its original URL — and svg-as-image refuses to load any non-data: resource, so the photo used to rasterize blank however well the <img> itself had been inlined. Before the fix: transparent result.
