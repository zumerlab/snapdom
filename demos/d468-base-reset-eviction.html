#468 — base reset silently omitted for tags evicted from the defaultStyle cache

Uses 40+ distinct tags so h3 (registered early) gets evicted from cache.defaultStyle (capped at 30) before the base-reset pass runs at the end of the capture. Before the fix, h3 got no reset rule, so the UA default margin-block-start: 1em came back inside the foreignObject and pushed the green marker bar (and everything below it) down — even though h3 { margin: 0 } is set on the live page. With the fix the green bar sits flush under the heading in both columns.
