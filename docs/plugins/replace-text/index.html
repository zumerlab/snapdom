@zumer/snapdom-plugins · MIT

Replace text in the capture.

Replaces DOM text in the clone using strings or regular expressions. Stylesheet and script text are left unchanged.

Source · MITChangelogShowcase demo

npm install @zumer/snapdom@latest @zumer/snapdom-plugins@latest

Usage

import { replaceText } from '@zumer/snapdom-plugins/replace-text';

snapdom(el, {
  plugins: [replaceText({
    replacements: [
      { find: 'DRAFT', replace: 'APPROVED' },
      { find: /\d{4}-\d{2}-\d{2}/, replace: '[REDACTED]' }
    ]
  })]
});

Options

OptionTypeDefaultDescription
replacementsArray<{ find: string|RegExp, replace: string }>[]List of find/replace pairs

Something missing?

Options are added for captures someone needed, not in advance. Open an issue with the element and the output you need.
