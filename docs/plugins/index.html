Plugins for SnapDOM.

Three products with a landing of their own, and a toolbox of smaller plugins grouped by the job they do. Every page has the options and a live demo. All of them are MIT: the products are packages of their own, the toolbox is one.

Install

npm install @zumer/snapdom@latest @zumer/snapdom-plugins@latest
npm install @zumer/snapdom-pdf @zumer/snapdom-vector @zumer/snapdom-stream

The first line is SnapDOM and the toolbox; the second, the three products, each a package of its own. Import a product from its package and a toolbox plugin from its subpath, and pass them in plugins. All of them need SnapDOM 3.4.0 or newer within 3.x.

import { snapdom } from '@zumer/snapdom'
import { redactInputs } from '@zumer/snapdom-plugins/redact-inputs'
import { pdf } from '@zumer/snapdom-pdf'

const result = await snapdom(el, { plugins: [redactInputs(), pdf()] })
const blob = await result.toPdf({ page: 'a4' })

The toolbox

Eleven plugins, each with one job. Prepare plugins change the clone before it renders; the others add an export method to the result.

Prepare

Change what the capture shows. The live page is never touched.

Redact inputsMask field values, hide blocks, drop attributesReplace textStrings or regular expressions, in the clone onlyFilterGrayscale, sepia, blur or any filter stringColor tintA blend-mode overlay with its own opacityTimestamp overlayDate, time or a custom formatter in a corner

Export

Other outputs from the same capture.

HTML exportThe clone with its styles and fonts as a documentASCII exportText or colored HTML, also frame by frame

Record

Record the live element over time.

GIF exportA built-in GIF89a encoder, no dependencyVideo exportMP4 or WebM through MediaRecorder

Context

Structured output for coding agents and visual QA.

Agent mapBadges on the image plus a JSON element mapContext exportAn outline or JSON tree of structure, text and state

Build your own

A plugin is an object with hooks. The plugin guide walks through one, and PLUGIN_SPEC.md is the contract: hook order, what each hook receives, and what it may change.
