What's a how-to?

Each how-to covers a capture or export task. Core recipes use images, SVG, Canvas and Blob; the PDF workflow uses an optional plugin. For portable HTML, structured context and maps, GIF or video, see the plugins. The framework guides cover refs and lifecycle timing in React, Vue, Next.js, Svelte, Angular and Lit.
