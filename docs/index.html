High-performance DOM engine · zero dependencies

Capture, modify and convert DOM elements into any format.

SnapDOM is an MIT JavaScript library that converts DOM elements to PNG, SVG or canvas, a faster html2canvas alternative. It runs in the browser. Images ship in the core; plugins turn the same capture into PDF, HTML, vector artwork, GIF, video or context for agents.

Why SnapDOM.

Fast, faithful, extensible and maintained. Check each claim yourself.

Speed
