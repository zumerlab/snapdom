A quick overview

html-to-image is a dom-to-image fork with TypeScript support. Its image helpers return data URLs, plus Canvas and Blob exports.

SnapDOM exposes capture and export lifecycle hooks. Official plugins, separate from the core exporters, add portable HTML, structured context and maps, searchable PDF, editable vector, GIF and video, plus filters, timestamps and text transformations.

When to use which

Choose SnapDOM when…

  • You need fast captures, including repeats of the same element (live benchmark).
  • Output must match the browser's rendering, pixel for pixel.
  • You need PDF, editable vector, HTML or agent context, through plugins or your own.
  • You want a library with a release about every week.

Check before migrating…

  • Existing html-to-image post-processing needs adapting to SnapDOM's plugin lifecycle.
  • Test open Shadow DOM, CSS counters and line-clamp on the components you ship.
  • html-to-image has its own font embedding controls and canvas-based encoding; option semantics differ.

Same task, side by side

Capture #card as a PNG and add the image to the page:

html-to-image

import { toPng } from 'html-to-image';

const dataUrl = await toPng(document.querySelector('#card'));
const img = new Image();
img.src = dataUrl;
document.body.appendChild(img);

SnapDOM

import { snapdom } from '@zumer/snapdom';

const img = await snapdom.toPng(document.querySelector('#card'));
document.body.appendChild(img);

Frequently asked questions

What is the difference between html-to-image and SnapDOM?

Both clone the DOM and render via foreignObject. SnapDOM adds capture lifecycle hooks, automatic reuse of eligible repeat captures, and official plugins for PDF, HTML, vector, GIF, video and agent context. Return types and options are in the migration table.

Does SnapDOM render web fonts better than html-to-image?

Both can embed @font-face declarations. SnapDOM 3 defaults to embedFonts: 'auto' for used web fonts and also has localFonts and excludeFonts. Check the exported text with your own font files and browser.

Can I add a watermark or filter without forking the library?

Yes. Use the colorTint, filter or timestampOverlay plugins, or write your own with two callbacks (afterClone / beforeExport). The plugins page has the full list.

How do I export to PDF?

Use the MIT pdf plugin. toPdf() returns a PDF Blob with selectable text, pagination and links. It ships on npm in @zumer/snapdom-plugins 4.x; the PDF reference covers installation and examples.
