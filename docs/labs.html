Rendering engines
SVG and html-in-canvas

SnapDOM has two rendering engines. SVG is the default; engine: 'html-in-canvas' paints the captured clone through the browser's native canvas API. Both exports below are PNG images.

The second engine is experimental and still needs a compatible browser with its canvas drawing flag enabled. For local development, run SNAPDOM_CANVAS_ENGINE=1 npm run site to include it in the build. Unsupported captures fall back to SVG.
