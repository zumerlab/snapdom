Live stream Plugin

The stream plugin keeps a canvas in step with a live element and repaints only the boxes that changed. The first frame is a full capture; after that, a changed card costs a few milliseconds instead of a full frame. Type in the card and watch the canvas follow.

Type here, the canvas follows

Each box repaints on its own when it changes.

live00
import { stream } from '@zumer/snapdom-plugins/stream'

const live = stream(el, { onFrame: f => console.log(f.full ? 'full' : 'patch', f.rects, f.ms) })
await live.ready
document.body.append(live.canvas)
// later: live.stop()
